# 🛡️ مسارات مهنية في الأمن السيبراني

دليل مفتوح لمن يبي يدخل مجال الأمن السيبراني أو يتخصص فيه: **٩ مسارات** مرتبة، لكل مسار الشهادات،
التدريب العملي المجاني، الأدوات، والمصادر. ومعه دليل لاختيار **بيئة العمل** المناسبة، ومرجع للجهات والضوابط وبرامج التدريب.

> 🗓️ آخر تحديث: **أكتوبر 2026** · الروابط تتغير مع الوقت، لو لقيت رابطًا ما يشتغل، بلّغ عنه عن طريق Issue.

## 🧭 أي مسار يناسبني؟

| إذا كنت... | جرّب |
|---|---|
| تحب تتبع الأدلة وحل اللغز | **SOC** · **الاستجابة للحوادث** · **التحليل الجنائي** |
| تحب تكسر الأشياء وتفهم كيف تشتغل | **اختبار الاختراق** |
| تحب القوانين والتنظيم والتقارير | **GRC** |
| تحب تبني وتؤتمت | **هندسة الأمن** · **الأمن السحابي** |
| تحب الشبكات والأجهزة | **أمن الشبكات** |
| تحب الأنظمة المؤسسية والتكامل | **IAM** |
| ما تدري | ابدأ بـ **SOC** أو **GRC**، فهي أسهل بوابتين دخولًا، ثم انتقل بعد سنة أو سنتين |

> 💡 **نصيحة:** المسارات تتقاطع كثيرًا. محلل SOC جيد يسهل عليه الانتقال للاستجابة أو الكشف، ومن بدأ بـ GRC وتعلم السحابة يصير مطلوبًا جدًا في الامتثال السحابي.

## 🧱 شكل أي مسار

كل ملف مسار مرتب بنفس الطريقة، عشان تعرف وين تدور:

1. **الفكرة والصعوبة** · 2. **الأدوار الوظيفية** · 3. **خارطة الطريق** · 4. **الشهادات حسب المستوى** · 5. **التدريب العملي** · 6. **الأدوات** · 7. **المهارات والمصادر**

### رموز الملفات
🆓 مجاني أو فيه مستوى مجاني · 💲 مدفوع · 🎓 فيه خصم أو مزايا للطلاب · ⚠️ تنبيه أو تغيير مهم

## 🆕 سجل التحديثات

**أكتوبر 2026**

- إضافة مسار **الأمن السحابي** (AWS وAzure وGCP، مع دليل بيئات المؤسسات السحابية)
- إعادة ترتيب المسارات داخل مجلد `paths/` بأرقام، وتوحيد قالب كل مسار
- إضافة الأدوار الوظيفية وخارطة الطريق وترتيب الشهادات حسب المستوى لكل مسار
- إضافة أدلة: [الأساسيات](./guides/00_Foundations.md) · [بيئات العمل](./guides/Work_Environments_Guide.md) · [الجهات والضوابط](./guides/Frameworks_and_Authorities.md)
- تحديث الشهادات: إيقاف AZ-500 (31 أغسطس 2026)، تحديث SC-200 وSC-300 (أكتوبر 2026)، اعتماد SCS-C03 لـ AWS
- تحديث روابط وأسماء: eJPT (INE)، HackTricks، Archer
- إزالة: RangeForce Community، صفحتين في GRC، رابط `sans-blue-team`، رابط `iamworkshop.com`
- نقل CEH إلى الشهادات الاختيارية في مسار SOC

> انتقلت ملفات المسارات من جذر المستودع إلى مجلد `paths/` (مثل `SOC_Path.md` ← `paths/01_SOC_Path.md`).

## ⚖️ إخلاء مسؤولية

المحتوى للتعليم والتوجيه المهني فقط. الأسعار والعروض والشروط تتغير، فتحقق من المصدر الرسمي قبل الشراء أو التسجيل. مارس الأدوات الهجومية في مختبراتك أو بتصريح كتابي فقط. الاستخدام غير المصرح به مخالف للأنظمة.
